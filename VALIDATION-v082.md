# FotoArchive 0.8.2 — каталог, карта и Telegram

Проверено 22 сентября 2026 года на Windows. Нагрузочные проверки используют
отдельные искусственные каталоги и изображения; реальные оригиналы не изменяются.

## Изменения

- Видимая фотография и относительный отступ сохраняются при изменении окна,
  масштаба миниатюр и DPI. Явная прокрутка отменяет отложенное восстановление.
- Раскрытие стопки сохраняет прежние пиксели до готовности записей, миниатюр
  и раскладки. Анимация располагается над прокручиваемой областью, поэтому
  сброс модели не открывает промежуточный пустой кадр. Плашка стопки компактнее.
- Панель сведений получает ненулевую ширину после скрытия. В просмотре дата
  стоит рядом с именем, кнопки навигации/масштаба имеют иконки и подсказки.
  Полоса видео поддерживает щелчок и перетаскивание.
- Частые запросы неподдерживаемых ролей Qt отклоняются через готовый набор
  значений без построения кортежа и проверки индекса для каждой строки.
  Эта оптимизация устранила задержки глубокого раскрытия при открытой карте.

## Карта

MapLibre GL JS 5.24.0, стиль @protomaps/basemaps 5.7.2, данные Protomaps v4
на основе OpenStreetMap. По умолчанию — Московская область. Есть улицы,
здания, водоёмы, парки, населённые пункты и административные границы
в соответствии с доступными данными и масштабом. Высота панели запоминается.

Мировой обзор (341 тайл, уровни 0–4), шрифты и значки скачиваются при запуске
в фоне. Детали до уровня 15 получаются по мере просмотра, более крупный
масштаб использует уже полученную геометрию. SQLite-кэш не имеет срока
истечения: существующие ресурсы после перезапуска не запрашиваются из сети.
Сбой одного запроса не создаёт готовую запись. Истёкший адрес исходного
архива обновляется только для отсутствующих данных. Сервер обязан отвечать
корректным HTTP Range; полный многогигабайтный архив не принимается.

Сетевой ввод-вывод работает вне потока интерфейса; загрузчики не удерживают
завершение приложения. Карта имеет собственное хранилище. Встроенная страница
получает только разрешённые ресурсы от локального сервера со случайным токеном.
Внешние URL из страницы заблокированы. Фотографии и каталог поставщикам
карт не передаются; запросы необходимых географических участков передаются.

Реальный запуск отдельного Windows-процесса и повторный запуск с запрещёнными
сетевыми запросами: Московская область, улицы Москвы, здания и весь мир
отрисованы без ошибок. В уличном фрагменте — 179 видимых объектов слоя зданий.
Сохранены одинаковые геометрия и подписи. Кэш после проверок — около 13,3 МиБ.
Без сети доступен мировой обзор и просмотренные масштабы/участки;
подробности новых областей требуют подключения.

Первичная загрузка графического компонента в отдельной упакованной проверке
заняла до 3,8 с; это не время переключения фильтров. Основное приложение
загружает его библиотеки до показа окна. Повторная отрисовка проверенных
масштабов из кэша занимала около 0,6–0,9 с. Полные отчёты и изображения карты:
`D:\FotoArchiveData\reports\v082-detailed-map`.

## Telegram

Кнопка «Отправить» присутствует в просмотре фото и видео. Меню открывается
по наведению или нажатию; контакты добавляются по нику и удаляются крестиком.
Контакты хранятся локально, отдельно от каталога. Оригинал прикладывается
как документ: преобразования и потери качества нет. Текст существующего
черновика не заменяется. Финальная отправка отсутствует в коде подготовки.

Проверка проведена через фактическую кнопку приложения в Telegram Desktop
7.2.9 с английским интерфейсом и контактом, указанным пользователем. В чате
оставлено тестовое PNG-вложение размером 3,2 КБ с включённым «Send as a document»;
сообщение не отправлялось. Личные снимки для проверки не использовались.

Переход в чат допускается только через кнопку внутри проверенного профиля;
кнопка отправки существующего черновика исключена даже при совпадении названия.
Тесты проверяют исходный путь и неизменность байтов для JPG, PNG, MP4 и RAW,
отсутствие финальной отправки, контакты, отмену и вложенный системный диалог.
Русские названия элементов предусмотрены, но реальная проверка русского
интерфейса Telegram не проводилась. Изменение UI Telegram может потребовать
обновления адаптера; ошибка останавливает подготовку, без запасного пути отправки.

## Проверки и нагрузка

- Полный набор: 234 теста; дополнительно проверки при DPI 150% и 200%.
- Сборка без установленного Python: виртуальные страницы, 18 раскрытий стопок
  в трёх раскладках, панель сведений и загрузка COM-компонентов Telegram.
- Нативная карта проверена также из собранного EXE без сети.
- HTTP-тесты проверяют частичные ответы, истёкший источник, конкурентные
  запросы, повторное открытие кэша без сети, шрифты/значки и границы сервера.

200 тысяч искусственных записей, 256 разных миниатюр, параллельная запись
в каталог. Обычное окно Windows с открытой подробной картой:
