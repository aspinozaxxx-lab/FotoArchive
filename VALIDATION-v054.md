# FotoArchive 0.5.4 — область подсчёта и пропущенные форматы

Независимый обход имён всех файлов в `F:\MyFoto` завершился без ошибок чтения и без пропущенных reparse points: 191 745 файлов в 3359 каталогах. JPG/JPEG/BMP — 99 233, RAW — 37 152, другие растровые форматы — 6607, ещё 2 MPO. Всего около 143 тысяч файлов изображений; это не число уникальных кадров. Видео — 2962. Отчёт: `D:\FotoArchiveData\reports\source-coverage-20260921.json` (MPO в нём отнесены к другим файлам).

В настройках и пользовательском снимке диалога подтверждены подключённые папки **2003–2014 включительно**. Только в этих папках со всеми подпапками: **73 686 файлов изображений**, из них **47 102 JPG/JPEG/BMP**, **26 508 RAW**, **76 других изображений**, дополнительно **280 видео**. Полная обработка метаданных поддерживаемых файлов закончена: 47 079 готовы, 23 завершились ошибкой чтения. Остановка числа «Каталог» не означает остановку моделей: за наблюдаемые 30,10 с завершились 176 эмбеддингов, 93 задания лиц, 45 заданий мест и 7 описаний; новых ошибок за этот интервал нет. Отчёт: `coverage-live-20260921.json`.

Теперь полный подсчёт сохраняет распределение по расширениям атомарно вместе со списком поддерживаемых файлов. Служебные файлы не увеличивают число изображений. При обновлении старого сохранённого подсчёта без распределения повторяется только чтение имён; очередь обработки фотографий и версии не меняются. Ошибка чтения папки не заменяет предыдущий подсчёт частичным. Список подключённых папок сохранён, расширение на весь архив не выполнялось.

В окне постоянно видны область подсчёта, все файлы изображений и отдельно поддерживаемые. «Состав каталога» открывает список папок, распределение по форматам и объясняет отдельные этапы обработки. Диалог добавления сообщает о поддерживаемых форматах; статус «Подключена · JPG/JPEG/BMP» не обещает обработку RAW.

**104 теста прошли за 12,21 с.** Дополнительно проверены совместимость прежнего подсчёта без повторного запуска моделей, точный состав только выбранных папок, исключение XMP/AAE из числа фотографий, сохранение распределения при перезапуске, скрытие устаревших данных при недоступном диске, отображение всей области и неподдерживаемых форматов.

Независимый проверочный каталог не импортировал ни одной фотографии. Подсчёт реальных выбранных папок занял **0,951 с** на прогретом файловом кэше и дал те же числа. Запрос прогресса в существующем синтетическом каталоге из 200 тысяч записей: **p95 0,241 с**. Исходная синтетическая база открывалась только для чтения, использовались временные таблицы. Отчёт: `v054-inventory.json`.
