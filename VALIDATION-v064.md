# FotoArchive 0.6.4

Обновление включает исправления 0.6.3, сборка которой ранее не была установлена: отдельное чтение обычной выдачи независимо от координатора GPU, отмена устаревшего SQL и запросов лиц, ограниченные очереди, получение метаданных только для нужной страницы.

Повторное переключение использует до четырёх списков идентификаторов в дисковых временных таблицах. Изменение состава, даты, формата или других полей фильтрации сбрасывает кэш через общий счётчик SQLite. Новые описания и результаты распознавания не требуют перестроения списка; сведения о кадре читаются заново. Удаление, замена и перемещение между типами материалов учитываются даже при неизменном общем числе записей.

История поискового индекса очищается каждые десять минут в потоке записи индекса. Недавние транзакции сохраняются для текущих запросов, незавершённые записи не удаляются. Очистка не выполняется в потоке интерфейса или обычного просмотра. Ошибка обслуживания записывается в журнал и не отменяет успешную запись или подтверждение очереди.

151 тест прошёл за 19,72 секунды: независимость просмотра от занятого координатора и писателя SQLite, отмена устаревших запросов, страницы, ограничение кэша, актуализация после изменения файлов и при обновлении описаний, сохранение результатов поиска при очистке индекса и очереди при сбое очистки.

Резервные копии баз, старые сборки и временные каталоги прежних проверок удалены по запросу пользователя. Ссылки из тестовых каталогов на рабочие модели/среду удалялись как ссылки без обхода целевых каталогов. Фактическое освобождение места измеряется по свободному месту диска: логические размеры завышены из-за жёстких ссылок на одни файлы. Рабочие миниатюры и превью сохранены для быстрого просмотра. Новая резервная копия перед установкой не создаётся.

Установленная сборка проверена: основной процесс 23092, рабочий процесс 22324, окно 396972. В окне проверены выдачи только фото (123 727) и только видео (2 536). Это действия агента для проверки исправления, не наблюдения действий пользователя; снимки окна не сохранялись.

Получение записей для интерфейса в установленном EXE: первое видео 0,357 с, первые фото 0,415 с, общий список 0,419 с. Повторные фильтры: p95 0,0096 с; серия 50 переключений завершилась актуальным результатом за 0,012 с. Это время получения данных, без измерения полного появления миниатюр на экране. Отчёт v064-installed-benchmark.json.

За 30,18 с после успешного запуска: +49 эмбеддингов, +30 снимков по лицам, +5 описаний, +16 заданий местоположения; число ошибок не изменилось. Отчёт v064-installed-progress.json. 10-минутный интервал автоматической очистки проверен тестами; длительное наблюдение установленной версии через такой интервал ещё не проводилось.

Очистка LanceDB сохранила 63 002 записи photos и 40 391 запись faces, а также проверенные примеры с их векторами. Старые версии сократились с 10 180/15 445 до 2/1 соответственно. PRAGMA quick_check вернул ok, подпись записанных параметров оригиналов до и после совпала; заново все исходные файлы не хешировались. Каталог источника не записывался. Векторный индекс после очистки около 221 МиБ; SQLite около 3,83 ГиБ, в том числе около 0,88 ГиБ свободных страниц для дальнейшей обработки — это не резервная копия. Повторный VACUUM работающей базы не запускался.

Фактическое освобождение D: относительно начала очистки — 23 078 891 520 байт (21,49 ГиБ), с учётом продолжившейся обработки. Резервных копий баз не осталось, отчёты занимают около 21 МиБ. Оставшиеся dist-v063, dist-v064 и build занимают около 2,00 ГиБ: автоматическая проверка отклонила удаление с сообщением blocked by policy; обход запрета не выполнялся. Отчёты v064-storage-cleanup.json, v064-index-cleanup.json и v064-storage-after.json.

При проверке нативного окна обнаружена несовместимая ICU из Poppler в PATH инструментов разработки. Qt использует одноимённую системную библиотеку Windows с другим набором экспортов. Исправлен FotoArchive.spec: такие ICU не включаются в последующие сборки, исправленная сборка повторно собрана. В установленной папке библиотека заменена проверенной копией Windows (удаление было отклонено автоматической проверкой). Повторный запуск окна, получение миниатюр и распознавание подтверждены.
